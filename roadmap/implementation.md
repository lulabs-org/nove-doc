## 实施路线图

> 定位：组织级 Agent 数据基础设施（数据网关）。首个落地场景：陆向谦实验室（教育：会议 / 订单 / 用户数据）。
> 本文档融合项目书中"里程碑与计划 / 交付物 / 迭代策略"的内容，与 [三年技术与 AI 演进路线图](./evolution) 配合阅读。

---

## 一、总体迭代策略

- **路线**：核心数据源接入 → AI 预处理与关联 → 多协议接口 → 人机权限与审计 → 平台化
- **节奏**：双周评审与验收；AI 拟定初稿 + 人工校对入库
- **优化**：持续改进数据质量与关联效果，数据与能力闭环进化

---

## 二、阶段规划

### 阶段一：数据汇聚 MVP（3-4 个月）
1. **基础架构搭建**
   - nove-api（NestJS）+ PostgreSQL + Prisma + Redis
   - 人机统一认证与权限体系（人类 + AI 独立身份）
   - nove-admin（React）基础框架

2. **核心数据源接入**
   - 会议数据（腾讯会议 / 飞书 Webhook + API，转写 / 摘要 / 行动项入库）
   - 订单与用户数据（业务系统同步）
   - 内置数据仓库格式定义（数据模型、元数据、溯源）

3. **基础 AI 预处理**
   - 接入外部 Agent（OpenClaw / Hermes 等）：代办自动总结、实体抽取等核心预处理
   - AiClient 封装（超时 / 重试 / 熔断 / 降级）
   - 异步 Job 模型（BullMQ）

### 阶段二：接口与智能（4-6 个月）
1. **多协议开放**
   - REST / GraphQL API（OpenAPI 契约）
   - MCP Server 暴露
   - nove-cli / nove-skills 可用

2. **AI 关联引擎**
   - Embedding 入库与向量索引
   - 跨数据源关联发现（"用户 ↔ 会议 ↔ 订单 ↔ 邮件"）
   - 知识图谱 / 语义层构建

3. **人机权限与审计**
   - AI scope 白名单授权
   - 全量审计（人类 + AI 行为可回放）

### 阶段三：平台化（4-5 个月）
1. **自定义数据接入**
   - 插件化连接器（新数据源 / 新数据格式）
   - 数据源管理界面（nove-admin）

2. **扩展与复制**
   - 多租户与数据隔离
   - 教育场景验证完成后拓展至其他组织
   - 性能优化、缓存策略、可观测性完善

## 三、12 周里程碑（M1-M6）

### 第1-2周（M1）：基础架构与核心数据接入
- **需求澄清与技术选型**：确认数据仓库定位与数据源清单（会议、订单、用户）
- **基础架构**：NestJS + Prisma + PostgreSQL + Redis 骨架；人机统一权限模型初版
- **会议数据接入**：腾讯会议 / 飞书 Webhook + API，转写 / 摘要 / 行动项入库
- **交付物**：项目骨架、会议数据接入链路、基础权限与审计

### 第3-4周（M2）：数据仓库与 AI 预处理
- **仓库格式**：内置数据仓库格式定义（数据模型、元数据、溯源）
- **AI 预处理**：引入 OpenClaw / Hermes 等外部 Agent 软件代办自动总结、实体抽取；AiClient 封装（超时/重试/熔断/降级）
- **异步任务引擎**：BullMQ Job 模型（queued → running → succeeded / failed）
- **交付物**：数据仓库核心模型、AI 预处理链路、Job 引擎

### 第5-6周（M3）：接口层与人机权限
- **REST / GraphQL API**：数据访问与操作接口（OpenAPI 契约驱动）
- **人机统一权限**：AI 独立身份（API Key / scope）、RBAC + ABAC、全量审计
- **nove-cli / nove-skills**：命令行与技能化访问雏形
- **交付物**：开放 API、人机权限体系、CLI / Skill 雏形

### 第7-8周（M4）：MCP 与关联引擎
- **MCP Server**：以 MCP 暴露数据仓库，供 LLM / Agent 直接调用
- **关联引擎**：Embedding 入库、跨数据源关联发现（"用户 ↔ 会议 ↔ 订单"）
- **开发者工作台**：数据源管理、权限配置、审计查询雏形
- **交付物**：MCP 服务、关联引擎初版、开发者工作台

### 第9-10周（M5）：nove-admin 与用户体验
- **nove-admin 开发**：React + Ant Design，数据查看 / 操作 / 审计界面
- **核心功能页面**：数据全景、数据源管理、权限配置、AI 行为审计
- **实时交互**：数据接入状态、任务进度可视化
- **交付物**：nove-admin、核心功能页面

### 第11周（M6）：测试优化与监控
- **内测与反馈**：用户内测、问题收集与优化迭代
- **运营看板**：数据接入量、接口调用、AI 任务、审计事件监控
- **安全加固**：漏洞扫描、权限测试、数据安全加强
- **交付物**：测试报告、监控看板、安全优化方案

### 第12周（Release）：发布与交付
- **正式发布**：v1.0 版本发布，生产环境部署
- **文档沉淀**：架构文档、运维手册、开发指南、接口文档
- **后续规划**：v1.x 版本规划、技术演进路线图
- **交付物**：正式产品、完整文档体系、运维支撑体系

## 四、交付物（v1.0）

- **nove-admin 应用**：用户与 AI 身份管理、数据查看、数据源管理、权限配置、审计查询
- **开放接口**：REST / GraphQL / MCP / CLI / Skill

### 技术交付物
- **后端服务与 API 文档**：RESTful API（NestJS）、OpenAPI 3.0 契约、SDK 与集成示例
- **异步任务系统**：会议转写、AI 预处理、批量关联分析

### 文档与培训交付

- **用户文档**：产品使用手册、管理员操作指南、常见问题、培训材料
