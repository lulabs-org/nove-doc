## 实施路线图

> 定位：个人 / 组织 / 企业智能数据仓库与 Agent 数据基础设施。首个落地场景：陆向谦实验室（教育：会议 / 订单 / 用户数据）。

### 阶段一：数据汇聚 MVP（3-4 个月）
1. **基础架构搭建**
   - nove-api（NestJS）+ PostgreSQL + Prisma + Redis
   - 人机统一认证与权限体系（人类 + AI 独立身份）
   - nove-admin（React）基础框架

2. **核心数据源接入**
   - 会议数据（腾讯会议 / 飞书 Webhook + API，转写 / 摘要 / 行动项入库）
   - 订单与用户数据（业务系统同步）
   - 内置数据仓库格式定义（数据模型、元数据、溯源）

3. **基础 AI 预处理**
   - nove-ai（FastAPI）起步：自动总结、实体抽取
   - AiClient 封装（超时 / 重试 / 熔断 / 降级）
   - 异步 Job 模型（BullMQ）

### 阶段二：接口与智能（4-6 个月）
1. **多协议开放**
   - REST / GraphQL API（OpenAPI 契约）
   - MCP Server 暴露
   - nove-cli / nove-skills 可用

2. **AI 关联引擎**
   - Embedding 入库与向量索引
   - 跨数据源关联发现（"用户 ↔ 会议 ↔ 订单 ↔ 邮件"）
   - 知识图谱 / 语义层构建

3. **人机权限与审计**
   - AI scope 白名单授权
   - 全量审计（人类 + AI 行为可回放）

### 阶段三：平台化（4-5 个月）
1. **自定义数据接入**
   - 插件化连接器（新数据源 / 新数据格式）
   - 数据源管理界面（nove-admin）

2. **扩展与复制**
   - 多租户与数据隔离
   - 教育场景验证完成后拓展至其他组织
   - 性能优化、缓存策略、可观测性完善
