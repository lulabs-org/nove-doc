# 需求与范围

> 本文档承接 [项目概述](./overview)，阐述 nove 数据仓库的核心用户、典型场景与 v1.0 范围边界。

## 核心用户

- **AI / Agent**：通过 API / MCP / Skill / CLI 读取数据、执行任务（主要消费者）。
- **数据提供方**：会议、订单、聊天、邮件、合同等外部系统，向仓库推送/被拉取数据。
- **人类用户（管理员 / 业务人员）**：通过 nove-admin 查看数据、配置权限、管理数据源、审计 AI 行为。
- **开发者 / 集成方**：接入新数据源（插件/自定义格式）、构建基于仓库的 Agent 应用。

## 典型场景

- **多源数据汇聚**：会议记录、订单、用户、聊天记录、客户对接、群聊、产品、邮件、合同等实时/定时入库。
- **AI 预处理与关联**：自动总结参会记录、抽取实体、建立"用户 ↔ 会议 ↔ 订单 ↔ 邮件"等关联，形成语义层。
- **Agent 数据调用**：外部 Agent 通过 MCP / Skill / API 按权限读取仓库数据，完成总结、分析、报告等任务。
- **人类管理操作**：管理员通过 nove-admin 查看数据全景、管理数据源与权限、审计 AI 访问。
- **自定义接入**：新数据形态通过插件或自定义格式接入，扩展仓库能力。

## 范围边界（v1.0）

- **包含**：核心数据源接入（会议、订单、用户）、基础 AI 预处理、API / MCP / Skill / CLI 接口、人机统一权限与审计、nove-admin 查看与操作、运营看板雏形。
- **暂不包含**：个人市场（个人 AI 数据/记忆产品，另行立项）、移动端/桌面端、复杂低代码平台、跨组织数据联邦（可于 v1.x 规划）。
