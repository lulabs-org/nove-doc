# 需求与范围

> 本文档承接 [项目概述](./overview)，阐述 nove 数据仓库的核心用户、典型场景与 v1.0 范围边界。

## 核心用户

- **AI / Agent**：通过 API / MCP / Skill / CLI 读取数据、执行任务（主要消费者）。
- **数据提供方**：会议、订单、微信小店、渠道等外部系统，向仓库推送/被拉取数据。
- **人类用户（管理员 / 业务人员）**：通过 nove-admin 查看数据、配置权限、管理数据源、审计 AI 行为。
- **开发者 / 集成方**：接入新数据源（插件/自定义格式）、构建基于仓库的 Agent 应用。

## 典型场景

- **多源数据汇聚**：会议记录（腾讯会议 / 飞书会议）、订单与退款、微信小店、产品、渠道、平台用户、用户等实时/定时入库；聊天记录、客户对接、合同等为规划中数据源。
- **AI 预处理与关联**：自动总结参会记录、抽取实体、生成周期跟踪报告；"用户 ↔ 会议 ↔ 订单"等关联发现、知识图谱为规划中能力（nove-ai）。
- **Agent 数据调用**：外部 Agent 通过 MCP / Skill / API / CLI 按权限读取仓库数据，完成总结、分析、报告等任务。
- **人类管理操作**：管理员通过 nove-admin 查看数据全景、管理数据源与权限、审计 AI 访问。
- **自定义接入**：新数据形态通过插件或自定义格式接入，扩展仓库能力。

## 范围边界（v1.0）

- **包含**：核心数据源接入（会议、订单、微信小店、产品、渠道、平台用户等，详见 [数据源接入矩阵](./data-sources)）、基础 AI 预处理（轻量调用已可用，重量能力规划中）、API / GraphQL / MCP / Skill / CLI 接口（能力状态见 [能力状态总览](./capabilities)）、人机统一权限与审计、nove-admin 查看与操作、运营看板雏形。
- **暂不包含**：个人市场（个人 AI 数据/记忆产品，另行立项）、移动端/桌面端、复杂低代码平台、跨组织数据联邦与商业化多租户复制（组织 / 部门 / 成员基础管理已实现，多租户隔离与对外复制属 v1.x 规划）。
